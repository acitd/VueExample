# VueExample

A minimal Vue starter project preconfigured with **Vue Router** and **StyleZero**, designed for fast development and clean builds.

## Prerequisites

Make sure the following tools are installed on your system:

* Bun
* StyleZero

If you don’t have them yet, install them using the commands below:

```sh
curl -fsSL https://bun.sh/install | bash
curl -fsS https://hub.stylezero.org/bin/last/?lin-x64-install | bash
```

## Install Dependencies

Install all project dependencies using Bun:

```sh
bun install
```

## Development

Start the development server with hot reloading:

```sh
bun dev
```

## Production Build

Build the project for production:

```sh
bun run build
```

The compiled files will be available in the `./dist` directory and ready for deployment.
